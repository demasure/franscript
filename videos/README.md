# 📹 Dossier Videos

## ⚠️ IMPORTANT

**Vous devez placer votre fichier vidéo ici pour que le site fonctionne.**

### Fichier requis :
```
videos/
└── ma_video.mp4    ← PLACEZ VOTRE VIDÉO ICI
```

Le fichier **ma_video.mp4** n'est PAS inclus dans le repository (fichiers vidéo trop volumineux pour Git).

## 📝 Fichiers fournis

- ✅ **ma_video.vtt** : Fichier de sous-titres exemple
- ✅ **INSTRUCTIONS.md** : Guide complet pour ajouter des vidéos

## 🚀 Comment ajouter votre vidéo

1. Trouvez ou créez un fichier vidéo MP4
2. Renommez-le exactement `ma_video.mp4`
3. Placez-le dans ce dossier (`videos/`)
4. Lancez le site et cliquez sur "Ma Première Vidéo"

## 📚 Ressources

**Où trouver des vidéos libres de droits ?**
- Pixabay : https://pixabay.com/videos/
- Pexels : https://www.pexels.com/videos/
- Videvo : https://www.videvo.net/

**Outils pour convertir en MP4 :**
- HandBrake (gratuit) : https://handbrake.fr/
- FFmpeg (ligne de commande)
- VLC Media Player (convertisseur intégré)
